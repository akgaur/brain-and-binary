# Hashmaps: Introduction & Key Concepts

## 🗝️ What is a Hashmap?
- Data structure for key-value storage.
- Fast lookup, insert, delete (average O(1)).

## 🔑 Key Concepts
- **Hash Function**: Maps keys to indices.
- **Collision Handling**: Chaining, open addressing.
- **Load Factor**: Controls resizing.

## 💡 MAANG Interview Approaches
- Frequency counting, duplicate detection.
- Two-sum, anagrams, grouping problems.
- Custom hash functions for objects.
- Practice edge cases: collisions, resizing, null keys/values.
