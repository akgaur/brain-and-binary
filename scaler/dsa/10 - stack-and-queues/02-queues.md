# Queues: Introduction & Key Concepts

## 🚦 What is a Queue?
- Linear data structure, FIFO (First In First Out).
- Enqueue to add, dequeue to remove.

## 🔑 Key Concepts
- **Array/Linked List Implementation**.
- **Circular Queue**: Wraps around.
- **Priority Queue**: Elements with priority.

## 💡 MAANG Interview Approaches
- Level order traversal (BFS), sliding window.
- Producer-consumer, scheduling.
- Practice edge cases: empty queue, overflow, underflow.
