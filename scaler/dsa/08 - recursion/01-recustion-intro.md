# Recursion: Introduction & Key Concepts

## 🔁 What is Recursion?
- A function calling itself to solve subproblems.
- Base case stops recursion; recursive case breaks problem down.

## 🔑 Key Concepts
- **Base Case**: Prevents infinite recursion.
- **Stack Overflow**: Too deep recursion without base case.
- **Tail Recursion**: Recursive call is the last operation.
- **Backtracking**: Systematically searching for solutions.

## 💡 MAANG Interview Approaches
- Classic problems: factorial, Fibonacci, permutations, combinations.
- Divide & conquer: merge sort, quick sort, binary search.
- Tree/graph traversals: DFS, subset generation.
- Practice edge cases: empty input, single element, deep recursion.
