# Stacks: Introduction & Key Concepts

## 🥞 What is a Stack?
- Linear data structure, LIFO (Last In First Out).
- Push to add, pop to remove.

## 🔑 Key Concepts
- **Array/Linked List Implementation**.
- **Peek/Top**: View last element.
- **Size/Empty**: Check status.

## 💡 MAANG Interview Approaches
- Parentheses matching, next greater element.
- Undo/redo, backtracking, DFS.
- Practice edge cases: empty stack, overflow.
