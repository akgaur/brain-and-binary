# Linked Lists: Introduction & Key Concepts

## 🔗 What is a Linked List?
- Linear data structure with nodes pointing to next node.
- Dynamic size, efficient insert/delete.

## 🔑 Key Concepts
- **Singly Linked List**: Each node points to next.
- **Doubly Linked List**: Nodes have prev and next pointers.
- **Circular Linked List**: Last node points to first.

## 💡 MAANG Interview Approaches
- Reversal, cycle detection (Floyd's algorithm).
- Merge, split, find middle, remove nth node.
- Edge cases: empty list, single node, cycles.
